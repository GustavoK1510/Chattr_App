# 💬 Chattr

A simple and modern real-time chat application built with **Flutter** and **Firebase**. Chattr demonstrates the implementation of user authentication, cloud database integration, real-time messaging, theme management, and clean UI architecture.

> **Status:** 🚧 In Development

---

## 📱 Features

- 🔐 **User Registration**
  - Create a new account using email and password.
  - Firebase Authentication integration.

- 🔑 **User Login**
  - Secure authentication with Firebase.

- 💬 **Real-Time Chat**
  - Send and receive messages instantly using Cloud Firestore.

- 🏠 **Home Page**
  - Clean and intuitive interface.
  - Navigation drawer for easy access to app features.

- ⚙️ **Settings**
  - Toggle between Light and Dark themes.

- 🌙 **Dark Mode**
  - Fully functional theme switching with instant updates.

- 🚪 **Logout**
  - Securely sign out of the application.
